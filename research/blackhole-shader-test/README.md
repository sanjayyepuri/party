# Black Hole Shader Test

A WebGL shader that creates a black hole gravitational lensing effect using the same color scheme as the invitation shader.

## Features

- **Gravitational Lensing**: Simulates how light bends around a black hole using radial distortion
- **Same Color Scheme**: Uses the same iterative pattern and color generation as the invitation shader
- **Interactive Controls**: Adjust black hole mass and distortion strength in real-time

## Controls

- **Animation Speed**: Controls the speed of the underlying pattern animation
- **Black Hole Mass**: Adjusts the strength of the gravitational effect (affects Schwarzschild radius)
- **Distortion Strength**: Controls how much the light bends around the black hole

## Running

```bash
npm install
npm start
```

The shader applies gravitational lensing distortion to the same iterative pattern used in the invitation shader, creating a warped, black hole-like effect at the center of the screen.
